    WHAT IT RUNS
    The dashboard chat starts Claude Code (via the Claude Agent SDK, using your own Claude account) in the project folder you pick.
    Agents it starts can read, create, edit and delete files and run shell commands in that folder.
    Hooks in .claude/settings.json forward events to this page on 127.0.0.1.
    The Windows folder browser is opened by a short PowerShell command (no data leaves your computer). Not available in Docker.
    A folder uploaded from a device is written only under the workspace folder, as a new project folder. Uploaded code is stored, not run. Project config (.claude, .mcp.json and similar) is skipped unless you include it, and git data is never uploaded. Agents you start in the folder can run commands.
    
  
    PRIVACY
    The dashboard listens on this computer only (127.0.0.1). If you turn on Tailscale access, devices on your tailnet can reach it through tailscale serve with an access token. There are no accounts and no analytics.
    Chats and projects are stored in .claude/live/projects.json on this computer.
    Nothing else leaves this computer except what Claude Code itself sends to Anthropic (your prompts and the files Claude reads).
    Account detection only checks that login files or environment variables exist. It never reads their contents. The Claude sign-in choice (your subscription or an API key) is stored on this computer; the login or key itself never is.
    It contacts api.github.com and codeload.github.com only to check for and download updates (no data about you or your projects; can be turned off in Updates above).
    
  
    ACCOUNTS
    Only checks that a login exists. The dashboard never reads or sends your logins; each CLI uses its own.
